Productos en Consignacion: Como Controlar Stock que No Es Tuyo

Facundo Luis Zabala Junio, 2026 8 min lectura

Vender productos en consignacion puede ampliar la oferta sin comprar stock por adelantado. Pero si no se separa bien, el negocio mezcla mercaderia propia con mercaderia de terceros y despues cuesta saber que se vendio, que se devuelve y que se debe pagar.

La consignacion funciona cuando cada producto tiene dueno, estado y liquidacion clara.

Separa stock propio de stock consignado

El primer paso es identificar que productos pertenecen al proveedor y cuales al negocio. Si ambos stocks se mezclan, las compras, ventas y reposiciones empiezan a mostrar datos incorrectos.

Registra condiciones por proveedor

Cada proveedor puede tener porcentajes, plazos y reglas distintas. Guarda comision, precio sugerido, plazo de liquidacion, plazo de devolucion y responsable de seguimiento.

Controla ventas y devoluciones

Cuando un producto consignado se vende, debe quedar asociado al proveedor correcto. Si se devuelve, tambien debe registrarse el motivo y el estado para saber si vuelve a exhibicion o se reclama.

Liquida con evidencia

La liquidacion debe incluir productos vendidos, comision, total a pagar y periodo cubierto. Con evidencia, el cierre con proveedores deja de depender de cuentas manuales.

Checklist para aplicarlo esta semana

  • Proveedor: revisarlo y mantenerlo actualizado para que el equipo trabaje con datos claros.
  • Producto consignado: revisarlo y mantenerlo actualizado para que el equipo trabaje con datos claros.
  • Cantidad recibida: revisarlo y mantenerlo actualizado para que el equipo trabaje con datos claros.
  • Cantidad vendida: revisarlo y mantenerlo actualizado para que el equipo trabaje con datos claros.
  • Comision o margen: revisarlo y mantenerlo actualizado para que el equipo trabaje con datos claros.
  • Liquidacion pendiente: revisarlo y mantenerlo actualizado para que el equipo trabaje con datos claros.
